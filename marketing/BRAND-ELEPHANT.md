# Marque Zokko = l’éléphant

**La marque, c’est l’éléphant.** Point.

- Fond blanc, rouge, vert, dégradé Guinée : **OK** — ce qui compte, c’est que **l’éléphant soit visible et grand**.
- Fichier logo : `logo-icon-officiel.png` (ne pas déformer, ne pas recoloriser).

## Dans chaque pub / reel / post

1. **Éléphant** = élément principal (grand, centré ou coin fort).
2. **Zokko** = nom à côté ou sous l’éléphant.
3. **Message trafic** = une phrase + `www.zokko.net`.
4. **Pas** confondre avec l’affiche poster « Vendez gratuitement » (c’est une pub différente).
